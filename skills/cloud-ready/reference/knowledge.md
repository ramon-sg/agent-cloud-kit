# Lo que se sabe de la nube de Claude Code

Cada hecho lleva su estado: `verificado` (alguien lo vio, o lo dice la documentación oficial, con
la fuente) o `por verificar`. Si en una sesión ves algo que no está aquí o que lo contradice, va
a "Hallazgos" de `docs/agent-cloud.md`, marcado "proponer al paquete" (ver `SKILL.md`).

Fuentes: "README" es el README del paquete `agent-cloud-kit`; "documentación" es la de Claude
Code en code.claude.com (revisada el 2026-11-03); "prueba en la nube, 2026-11-02" son sesiones de
prueba del paquete (las del 2026-11-03 probaron Electron y Expo, con la red Limitado más la lista de gestores de paquetes); "sesión en la nube, 2026-10" son sesiones de prueba de otro repo preparado
para la nube.
